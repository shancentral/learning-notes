## Setup Tests for Bucks2Bar

- /setupTests (Slash command). Equivalent of manually promting: Set up tests in the Project
- @workspace (Chart participant). Will be auto added when selecting a slash command
- Typing / or @ will give suggestions for Slash commands or Chart participants
- Choose Vitest for Unit testing. Playwright for end-to-end testing
- In Plan mode review the Test setup and click **Apply Changes**
- Whenever Copilot runs a node command you need to approve it by clicking **Approve** button
- You can also select **Always allow Command** for all further same command requests in the context. Prefer not to use this
- Allow edits to Sensitive files? Approve it by clicking **Approve** button
